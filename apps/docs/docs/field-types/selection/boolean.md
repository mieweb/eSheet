# boolean

Binary Yes/No field.

## Properties

No explicit `options` needed. Built-in Yes and No options are used.

## Answer Format

```yaml
selected:
  id: yes-or-no
  value: 'Yes'
```

## Example

```yaml
id: allergies
fieldType: boolean
question: Do you have any known allergies?
```
